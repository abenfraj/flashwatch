The default display, simulated. In a game the chat lines come from League itself; Flashwatch only reads them.

It reads your screen. It never touches the game.

Flashwatch reads the chat you can already see, and the read-only feed the game itself publishes on your PC for companion apps — the same information as the scoreboard. Then it does the arithmetic you would otherwise do in your head.

Flashwatch is an independent project, not affiliated with or endorsed by Riot Games. The source is public, and every release is built from it by an automated workflow you can inspect.

From a chat line to a timer

Nothing is guessed. Every timer starts from a sentence the game prints itself, and only ever prints about the enemy team.

A ping counts too

A spell named without being announced as cast still starts a timer, with a ? beside it. Doubt costs a question mark, never a wrong time.

Dated by the game clock

Announcements are dated by the match clock, so a line read two seconds late costs nothing.

A running timer stays put

The same line read again, or one revealed by scrolling the chat, can't shift a countdown that is already running.

Test it without a game

The Test button reads a real game frame that ships with the program, from finding the chat to starting the timers.

Installed in three minutes

One file, no installer, no administrator rights. Windows 10 or 11, 64-bit.

  1. 1

    Download the file

    A single .exe — no Python, no installer. Put it in a folder of its own, say Documents\Flashwatch: it keeps its settings in an assets folder next to itself.

  2. 2

    Get past the Windows warning

    Double-click. Windows says “Windows protected your PC” because the program is not signed. Click More info, then Run anyway.

  3. 3

    Look for the tray icon

    No window opens: Flashwatch lives in the notification area, bottom right of the taskbar, sometimes under the ^. Double-click it for the settings.

Questions

Windows says the file is dangerous, is that normal?
Yes. An executable without a signing certificate triggers SmartScreen (“Windows protected your PC”), and sometimes a browser warning on download. Some antivirus products also flag programs packaged this way on principle: if yours deletes the file, you have to allow it explicitly. Signing the program would mean paying for a certificate.
Nothing shows up during my match.
In order: is League in borderless windowed? Does the program's language match your client's? Has an enemy actually used a summoner spell yet — with no announcement, the display stays deliberately quiet. If all of that is fine, press Test on the home page: it reads a real game frame that ships with the program, so a pass means everything but the capture of your own screen works. If it passes and your match still shows nothing, open Troubleshooting → Frame the chat and look at what the area really reads.
Is it heavy on resources?
No. Idle, the loop costs about 0.2 % of one core: the chat area image is compared from one capture to the next, and text recognition only runs when something changed. A few percent during an active read, on a single core.
Can I run it twice?
The program handles it: the second copy tells you and bows out, rather than reading the same chat twice and drawing two displays. Since nothing appears for the first two or three seconds, one double-click too many is easily done.
Where are my settings?
In an assets folder created next to the executable: settings, cached icons and the flashwatch.log file. The program is portable — move the folder and you keep everything. If the location is read-only, it falls back to %LOCALAPPDATA%\Flashwatch.
Is it just a Flash timer?
No — it is a timer for every summoner spell. Flash is the one everybody counts, so it is the one people ask about, but Teleport, Heal, Ignite, Exhaust, Barrier, Cleanse, Ghost and Smite are tracked exactly the same way, from the same announcement, with the cooldown the game gives each of them. Ultimates too, if you want them.
What about enemy ultimates?
Tracked too, but marked as an estimate: their cooldown depends on rank and ability haste, neither of which is visible on screen. The rank is inferred from the match clock, and the estimate is replaced by the exact value if a line states a remaining time.
Does it work at 1440p, 4K, on two monitors?
Yes. No coordinate is hardcoded: the chat area is recognised by its content, not its position, which covers resolutions, HUD scales and windowed mode. The display goes wherever you want on any monitor.
